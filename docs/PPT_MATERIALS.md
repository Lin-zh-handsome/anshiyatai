# PPT素材索引

建议按“问题规模 → 处理流程 → 精度与压缩 → 关键节点 → 资源与下一阶段”讲述。

## 1. 问题规模与目标

267801节点、101帧、3个位移分量，共803403个空间自由度、27047901条节点记录，模拟时间0～0.1秒。目标是建立同工况位移场压缩与重建基线。

## 2. 方法流程

原始TXT（文本） → 按节点编号对齐与逐帧校验 → 磁盘快照 → 时间均值中心化 → 101×101时间内积矩阵 → POD（本征正交分解） → 多阶重建与误差评价。

核心公式：`Uhat = mean + coefficients[:, :r] @ modes[:r]`。累计能量针对中心化快照；全场相对L2误差以未中心化的原始快照为分母，两者不能混用。

## 3. 精度与压缩

推荐图：[多阶误差](../outputs/v01/04_rank_errors.png)、[累计能量](../outputs/v01/01_pod_energy.png)。

## 4. 关键节点响应

推荐图：[关键节点三方向与总位移](../outputs/v01/03_key_node_curves.png)。

节点56877由全场数据自动搜索确认为最大总位移节点，与客户资料标注一致。实际峰值10.42835352，发生于0.088秒；10阶重建峰值幅值误差0.000114599，峰值时间误差0秒。节点173465也已输出DX/DY/DZ（X/Y/Z向位移）与总位移对比。

原始/重建曲线数据见[key_node_curves.csv](../outputs/v01/key_node_curves.csv)；峰值与误差见[key_node_metrics.csv](../outputs/v01/key_node_metrics.csv)。总位移为三个分量的欧氏范数，不是分量相加。

## 5. 资源与工程验证

真实解析及计算共127.60秒，峰值内存660.88 MiB（二进制兆字节）；18项自动化测试通过。总时间包含解析106.46秒、分解5.46秒、全场评估12.54秒及绘图1.51秒，不包含上传。

推荐图：[逐帧误差](../outputs/v01/02_reconstruction_rmse.png)。原始全零帧的相对误差在CSV中留空，绝对误差仍正常计算。

## 6. 汇报时应保持的口径

- 结果属于同工况、训练内压缩与重建。
- 全场误差和关键节点误差分别解释；位移使用数据原单位，待客户确认。
- 存储比不等于有限元求解加速比，本次没有原有限元求解耗时对照。
- 尚未开展新载荷预测、跨工况泛化或强非线性稳定性验证。
- 下一阶段需要精确三方向载荷序列、单位和分配方式，以及多工况配对位移数据；应力评价还需要相应数值与网格/材料信息。
