# 瞬态有限元时间步长内插

残差 MLP（多层感知机）的合并全场均方根误差较线性插值升高 249.91%，局部三次的误差最低。

全部工况合并均方根误差分别为线性 0.0455203、局部三次 0.0139815、残差 MLP 0.15928（原始位移单位）。
全帧推理时间中位数分别为 1.590、4.067、27.252 毫秒。
传统插值运行于 CPU，残差 MLP 运行于 NVIDIA GeForce RTX 3090。计时包含输入取片、计算和模型主机/显卡传输，排除加载模型、写盘与误差统计。

## 划分与比较

- 用同一套偶数帧时间块训练与验证，每工况 118 个训练窗口、48 个验证窗口。两者的输入与监督帧均完全分离。
- 训练和验证使用 4、6、8 毫秒端点间隔，最终评测只在 2 毫秒端点间隔的中点进行。每个工况的 50 个奇数毫秒帧均为保留标签，检验同工况从较粗间隔迁移到较细间隔。
- 线性与模型使用相邻两个偶数端点。局部三次采用四个偶数帧的拉格朗日多项式，内部通常为目标前后各两帧，首尾分别用 [0, 2, 4, 6] 与 [94, 96, 98, 100] 毫秒。
- 最低验证损失出现在第 1/32 轮。该轮验证均方误差 0.0324501，验证线性插值 0.0407972。末轮训练/验证均方误差为 0.00660801/0.0564447。训练损失继续下降，而验证损失高于最佳轮，表明后续训练出现时间窗口过拟合。
- 位移真值三维向量均方根不超过 1e-12 时，单帧相对 L2（欧氏范数误差比）留空。本次近零真值帧数为 0。

## 残差分析

理想修正量为真值减线性插值。下表比较模型修正与理想修正的全场范数比例和余弦相似度。
| 工况 | 修正范数比 | 余弦相似度 |
|---|---:|---:|
| XForceOnly_1x | 3.612 | 0.440 |
| XYZForce_1x | 2.688 | 0.289 |
| XYZForce_2x | 5.909 | 0.430 |
| YForceOnly_1x | 23.876 | 0.089 |
| YXZForce_2.5x | 3.498 | 0.298 |
| ZForceOnly_1x | 7.006 | 0.178 |

当修正范数比大于两倍余弦相似度时，残差修正会增大全场平方误差。该条件来自修正后平方误差的展开。结果表中的分量误差、三维向量误差和最大误差均使用原始位移单位。

## 产物

- summary.csv 与 per_frame.csv 包含全局、工况、逐帧指标与实际输入帧。
- residual_diagnostics.csv 包含残差量级、方向和逐帧胜率。
- figures 包含训练损失、逐帧均方根误差、关键节点曲线和 73 毫秒三维点云误差。误差散点图绘制固定随机采样节点与各方法误差最大的节点，全部节点已参与评测。
- predictions 保存三个方法的全部保留帧，以及节点 ID、帧索引和时间戳。

## 合并残差诊断

合并六工况后，模型修正量范数是理想修正量的 3.676 倍，余弦相似度为 0.308。模型在 0/6 个工况的全场均方根误差低于线性插值。
