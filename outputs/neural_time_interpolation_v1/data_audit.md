# 数据检查报告

从一个 RAR 分卷档案的实际成员识别 6 个位移工况。
读取 6 个分卷。每个工况有 267,801 个节点，101 帧，0–0.100 s，间隔 0.001 s。
初始坐标来自独立文件 source_coordinates.txt。物理时间取自 time_mapping.csv 中的 Time 标签映射。
节点以初始坐标文件的 ID 顺序对齐。位移缓存为单精度，节点 ID 为 64 位整数。
载荷倍率沿用供应方文件名。载荷和约束反力文件保留在原档案中，模型使用初始坐标、位移和时间条件。
