# X 单轴工况时间步长内插 V2

训练和评估均以四帧真实历史初始化。每个目标只进行一次直接预测。所有时间段用于拟合，测试保留的是预测跨度 3、5、7 毫秒。

## 数据、模型与权重

- 复用 XForceOnly_1x 的 101 帧、267,801 个节点和三向位移。原始 51 点 X 向载荷每 2 毫秒采样，用分段线性插值对齐，保留原载荷值、位移单位和节点顺序。数据审计见 data_audit.json。
- 以 0 毫秒为参考拟合一套全轨迹 POD（本征正交分解）基。所有预测方法使用相同目标时刻。状态保持和常速度由实际全场历史直接计算。
- 条件 TCN（时序卷积网络）用两层因果卷积编码低维状态、历史时间间隔和 X 向载荷，用独立多层感知机编码 Δt，并融合未来区间起点、终点与平均载荷。更新由当前状态加上 Δt 乘变化率组成。
- 每轮覆盖所有合法窗口，各已见跨度的归一化均方误差等权。固定模型先训练，仅使用 1 毫秒。可变模型只使用 1、2、4、6、8 毫秒，AdamW（解耦权重衰减优化器）、梯度裁剪与余弦学习率调度。以已见跨度归一化均方误差最低的权重定型，之后才计算 3、5、7 毫秒指标。

## 结论

- 固定 1 毫秒模型在 97 个训练窗口上的全场 RMSE 为 0.00821783，相对 L2 为 0.98789%，选中第 1000 轮，归一化系数均方误差为 0.000171803。
- 可变步长模型选中第 1800 轮。在未见跨度中，优于常速度的跨度为 3、5、7 毫秒。
- 未见跨度的 POD 真值重构相对误差为 0.020488%–0.02062%。可变模型的低维预测项占全场平方误差 99.9994%–99.9997%。
- NVIDIA GeForce RTX 3090 上，变步长模型的单样本低维前向中位数为 0.577–0.617 毫秒。计时使用已在设备上的张量，包含设备同步，编码、解码和文件读取未计入。各步长和固定模型计时见 summary.csv。
- 结果只量化同一条已学习有限元轨迹的未见预测跨度。各窗口相互重叠。这些结果不代表独立轨迹、跨工况或有限元求解器数值积分步长的泛化。
